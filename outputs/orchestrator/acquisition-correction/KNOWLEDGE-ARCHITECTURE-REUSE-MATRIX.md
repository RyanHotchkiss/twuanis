## Retrieval guarantees and existing indexes

- Geography IDs remain decimal-string ontology identities. Province/Canton/District ancestry and official-code prefixes are checked. Existing `idx_ontology_parent`, `idx_ontology_official_code`, `idx_ontology_type` and ontology primary key are available; see `query-indexes.json` for the exact isolated definitions.
- PRIVATE membership access uses `listings_ontology_terms_pkey(listing_id, ontology_term_id)` and `listings_ontology_terms_term_listing_idx(ontology_term_id, listing_id)`. Existing listing status/transaction indexes remain unchanged. SQL chooses indexes or scans according to actual fixture size; no new indexes were justified or added.
- BANK uses existing offering/property, binding, latest-classification, financial-event, policy and publication indexes. `query-plans.json` records the exact scoped SQL and EXPLAIN ANALYZE/BUFFERS results. The global visibility/revision calculation still examines broader identities. Only the selected raw observations cross the analytical API boundary; minimal excluded identities remain required provenance.
- PRIVATE raw reuse is execution-local and bound to account, request/execution, population, authorization terms, exact canonical boundary and evidence mode. The first immutable raw snapshot contains its evidence revision. A separate freshness phase reacquires it and validates source identity; no persistent cross-request cache exists.
- BANK raw reuse additionally binds the scoped request and cursor, carries the unchanged global source revision, and retains database-verified inclusion/exclusion identities. The witness validator compares the exact recorded observations and complete membership to authoritative SQL at finalization and commitment.
- Canonical membership/label reuse is limited to identical ordered listing IDs and dimensions within that same execution phase. This does not authorize reuse after a term, scope, account or phase changes.

## Proprietary boundary

The seventeen reducers, cohort construction, analytical methodologies, invocation graph, execution witness and methodology archives remain server-only. The client import graph check and production build accompany this packet. None of these are appropriate public Knowledge Architecture exports. Future reuse must expose the minimum permitted canonical facts and relationships through a separately approved public or authenticated projection, not through the internal acquisition RPC.
